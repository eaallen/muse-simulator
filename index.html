Muse Simulator

A clickable replica of the Muse phone app, built as a custom web component. It replaces videos in the Build With Muse textbook: each lesson loads its own setup and the student performs the moves instead of watching them. This page is also the acceptance test from the spec: one script, one tag, no other code.

Completion events (the gradebook hook)

No setup completed yet. Finish one and its muse-simulator-complete event lands here, the same event an AvailaBooks page can forward to the gradebook.

Embed it in a lesson page: include the component script once, then drop in the tag with the setup for that lesson, for example <muse-simulator setup="ch2-daily-watch"></muse-simulator>. The component is encapsulated, so the book page styles cannot break it, and it cannot disturb the page.
