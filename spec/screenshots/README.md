# Screenshot index

Reference screenshots for the Muse Simulator build. The replica is drawn UI; these images were the layout and content references it was built against.

Note: the PNG files themselves are not in this repository yet. The GitHub connection used to publish this repo accepts text files only, so the images are indexed here and live in the course files (`muse-simulator-spec/screenshots/`) until they are uploaded through GitHub's web upload.

## From Eli's phone (real app, dark mode)

- `real-main-chat-dark-mode.png` — The real main chat in dark mode. Reference for the replica's dark theme: agent messages as plain text on the near black background, the icon only tab bar, the header with the circular menu button, the avatar with its "is working" status, the Invite pill, and the pill composer with the stop button while the agent works.
- `real-sidebar-dark-mode.png` — The real sidebar, open. Reference for the Free Explore drawer: the agent name at the top, the TABS section with the reorder note, SIDE CHATS with title only rows and a blue unread dot, and the bottom bar with the Settings gear, Search pill, and compose button.
